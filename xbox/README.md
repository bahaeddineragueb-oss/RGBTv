# RGBTv for Xbox Series S / X (and Xbox One)

Native UWP app: a thin C# shell hosting **WebView2** with the very same HTML5 app used by the webOS, Android and
Windows builds (`app/` → `RGBTv.Xbox/www/`). Gamepad-driven, full-screen 1080p, native HTTP bridge for IPTV panels.

```
xbox/
├─ RGBTv.Xbox.sln
├─ RGBTv.Xbox/
│  ├─ App.xaml(.cs)          UWP application (no virtual cursor, 1:1 pixels, WebView2 flags)
│  ├─ MainPage.xaml(.cs)     WebView2 host: virtual host https://app.rgbtv/, fetch bridge, SMTC, Back button
│  ├─ Package.appxmanifest   identity, capabilities (internetClient, hevcPlayback), tiles
│  ├─ Assets/                tiles + splash
│  └─ www/                   ← generated by `node sync.js` (copy of ../app)
├─ sync.js                   copies ../app → RGBTv.Xbox/www
└─ build.cmd                 one-shot Release build → release\*.msix (self-signed test cert)
```

## 1. What you need (one time)

| Item | Why | Cost |
|---|---|---|
| Windows 10/11 PC | Visual Studio only runs on Windows | – |
| **Visual Studio 2022 Community** with workload **"Universal Windows Platform development"** (tick *Windows 11 SDK 10.0.26100* and *.NET Native*) | compiles the UWP shell | free |
| **Node.js** | `sync.js` copies the web app | free |
| **Microsoft Partner Center developer account** | required to switch the console into Developer Mode | ≈ 19 USD once |
| **Dev Mode Activation** app on the Xbox (from the Store) | flips the console between Retail and Dev mode | free |

> Without a developer account there is no way to run your own app on a retail Xbox. Alternative with zero cost:
> run the Windows build of RGBTv on a PC on the same network and open it with Edge on the Xbox (see the bottom).

## 2. Build the package on your PC

1. Copy the whole `RGBTv` folder to the PC.
2. Open **"Developer Command Prompt for VS 2022"**, then:
   ```bat
   cd RGBTv\xbox
   build.cmd
   ```
   The first run creates `RGBTv.Xbox\RGBTv_Test.pfx` (password `rgbtv`), syncs `www/`, restores NuGet
   (Microsoft.UI.Xaml 2.8.7 + Microsoft.Web.WebView2 1.0.3179.45) and builds **Release | x64**.
3. Output: `xbox\release\RGBTv.Xbox_2.1.0.0_x64_Test\`
   * `RGBTv.Xbox_2.1.0.0_x64.msix`
   * `Dependencies\x64\Microsoft.NET.Native.*.appx`, `Microsoft.VCLibs.*.appx`, `Microsoft.UI.Xaml.2.8.appx`

Or open `RGBTv.Xbox.sln` in Visual Studio → Configuration **Release / x64** → *Project ▸ Publish ▸ Create App Packages ▸ Sideloading*.

## 3. Put the Xbox into Developer Mode

1. On the console install **Dev Mode Activation** from the Store, open it, sign in with the account that owns the
   Partner Center registration and follow the steps; the console restarts in Dev Mode.
2. In Dev Mode open **Dev Home** → *Remote Access Settings* → enable **Xbox Device Portal**, set a user/password,
   note the address (e.g. `https://192.168.1.50:11443`).

## 4. Install RGBTv on the console (Device Portal, no Visual Studio needed)

1. Open the Device Portal address in a browser on your PC, accept the certificate warning, log in.
2. **Home ▸ My games & apps ▸ Add** → choose the `.msix`, then *Next* and add the three dependency `.appx`
   files from `Dependencies\x64`, then **Start**.
3. RGBTv appears under *Games & apps* in Dev Home → launch it.

Alternative: in Visual Studio set *Debug ▸ Target device: Remote Machine*, address = console IP,
Authentication *Universal (Unencrypted Protocol)*, press **F5**; enter the PIN shown in Dev Home when asked.

## 5. Controller mapping

| Controller | Action |
|---|---|
| D-pad / left stick | move focus |
| **A** | OK |
| **B** | Back (from the profile screen: exit) |
| **X** | Red button (favorite / profile menu) |
| **Y** | Yellow (search / lock channel) |
| **LB / RB** | channel − / + (previous / next section outside the player) |
| **LT / RT** | rewind / fast-forward |
| **Menu (☰)** | Info / stream statistics |
| **View (⧉)** | Favorites |
| Left stick click | Play/Pause |
| Right stick click | Blue (stats) |
| Media remote / headset media keys | Play, Pause, Stop, Next, Previous (via SMTC) |

Typing (server URL, user, password) uses the on-screen keyboard of the app; a USB keyboard also works.
**Add from phone** (QR) is *not* available on Xbox (UWP apps cannot listen on a LAN port) — type the server or
use the same profile you already have on the TV/Windows.

## 6. Notes / limits

* Playback: HLS (`.m3u8`) via native Chromium or hls.js, MP4/MKV(h264/aac) via the native `<video>`.
  Raw MPEG-TS live streams are not supported by Chromium → the app forces the *Live stream format* setting to
  HLS on Xbox.
* Dev Mode caps memory for apps; keep the *Live preview window* setting off on Xbox One (Series S/X are fine).
* Dev Mode consoles switch back to Retail from Dev Home ▸ *Leave Dev Mode* (the app is removed in Retail mode).
  Publishing to the Store for retail consoles requires Store certification (same project, *Associate App with the Store*).
* The app is edge-to-edge; TV overscan margins are already part of the 1920×1080 design.

## Zero-cost alternative (no Dev Mode)

Retail Xbox consoles can only run Store apps or Edge. RGBTv's IPTV API calls need a CORS-free context, so a plain
web-hosted copy in Edge will not connect to most panels. The realistic free options are the Windows build on a PC
(HDMI to the TV) or the webOS / Android builds. Dev Mode (steps above) is the way to run the native Xbox app.
